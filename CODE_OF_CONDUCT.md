# Code of conduct

## Our commitment

We are committed to a respectful, inclusive, and harassment-free community for everyone, regardless of
background, identity, experience, or level of expertise.

## Expected behavior

- Discuss ideas and code with empathy, precision, and respect.
- Give actionable feedback and keep technical disagreement focused on evidence and trade-offs.
- Respect privacy, licensing, attribution, and responsible-disclosure boundaries.
- Never publish credentials, personal data, or private design material.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate intimidation, personal
attacks, or publishing another person's private information are not acceptable in any project space.

## Enforcement and scope

Maintainers may edit or remove contributions and restrict participation when behavior is unsafe or
disruptive. Report conduct concerns privately through the repository owner's GitHub profile. This policy
applies in repository discussions, issues, pull requests, reviews, and public spaces where a person is
representing the project. Security reports use [SECURITY.md](SECURITY.md).
