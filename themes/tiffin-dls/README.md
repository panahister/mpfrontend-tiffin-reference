# Tiffin public sample theme

This consumer-owned theme is independently authored for the public Tiffin reference. It implements the
neutral MP Frontend semantic variables for Light, Dark and System modes under
`data-brand="reference-dls"`.

No private Figma file key, export, token provenance, library link or generated ownership state is part
of this repository. Products that own an approved Figma/DLS can replace this sample with their own
normalized local export and attach it through `mpfrontend design attach --source existing`.
