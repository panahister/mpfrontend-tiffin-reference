# Visual assets

These repository-owned assets present the Tiffin reference architecture and may be used in the README,
GitHub repository settings, and project announcements.

- `ecosystem-light.svg` and `ecosystem-dark.svg` are the theme-aware README architecture artwork.
- `social-preview.svg` is the editable source for repository and announcement artwork.
- `social-preview.png` is the 1280 × 640 upload-ready GitHub social preview.

Keep the diagram aligned with the product topology in [`../ARCHITECTURE.md`](../ARCHITECTURE.md). Avoid
adding credentials, private design identifiers, or unlicensed third-party imagery.
