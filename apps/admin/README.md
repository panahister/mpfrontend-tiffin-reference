# Tiffin operations application

The operations application is an independently buildable Next.js workspace for restaurant managers and
couriers. Role-aware capabilities expose menu/media, kitchen, dispatch, and position work without turning
the frontend into an authorization authority.

City and platform administrators belong to the backend Access/governance boundary and intentionally do
not receive restaurant or courier operations solely from their administrative role. See the
[demo guide](../../docs/DEMO-GUIDE.md) for the account-to-surface mapping.

Run the complete product topology through the repository root and
[local development guide](../../docs/LOCAL-DEVELOPMENT.md).
